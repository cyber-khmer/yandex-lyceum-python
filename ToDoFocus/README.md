# ⚡ TodoFocus — Планировщик задач с календарём

## 🎯 Идея проекта
**TodoFocus** — это локальное десктопное приложение для управления временем (тайм-менеджмента). Главная проблема современного человека — перегруженность информацией. Мы держим в голове десятки задач и часто забываем о важном. TodoFocus решает эту проблему методом «выгрузки мыслей»: пользователь переносит все дела из головы на экран, освобождая ресурс мозга для самой работы.

## 🚀 Основные возможности
- **Календарь:** Привязка задач к конкретным датам. При переключении даты список обновляется.
- **Управление задачами:** Добавление (кнопка «+» или Enter), удаление (кнопка «🗑» или клавиша Delete).
- **Напоминания:** Возможность указать время для задачи. В назначенный момент всплывает системное уведомление.
- **Отметка выполнения:** Чекбоксы с зачёркиванием текста и выделением выполненных задач зелёным цветом.
- **Empty State:** Если на выбранный день задач нет, отображается картинка-заглушка с надписью «Нет задач».
- **Автологин:** При повторном запуске приложение пропускает окно знакомства и сразу открывает календарь, подтягивая имя пользователя из файла.
- **Тёмная тема:** Современный интерфейс в стиле Catppuccin Mocha (QSS).

## 🛠 Стек технологий
- **Язык:** Python 3.10+
- **GUI:** PyQt6 (Qt Designer для `.ui` файлов)
- **Хранение данных:** JSON (`tasks.json`)
- **Стилизация:** QSS (Qt Style Sheets)

## 🧠 Ключевые технические решения
1. **Источник правды:** Все данные хранятся в словаре `self.all_tasks` внутри `main_window.py`. Формат: `{ "дата": [ {"text": "...", "done": False, "time": "14:30"}, ... ] }`. Интерфейс (`QListWidget`) является лишь отображением этих данных.
2. **Защита от рекурсии:** В методе `choice_date` используется `blockSignals(True/False)`. Это предотвращает бесконечный цикл вызовов `itemChanged`, который возникает при программной расстановке чекбоксов.
3. **Модульность:** Файл `storage.py` не знает о существовании интерфейса. Он умеет только читать и писать JSON. Это позволяет легко заменить JSON на SQLite в будущем.
4. **Асинхронность напоминаний:** Для проверки времени используется `QTimer`, который каждые 30 секунд сверяет текущее время с задачами на сегодня. Флаг `reminded_tasks` защищает от повторных уведомлений.
5. **Диалоговые окна:** Для выбора времени используется `QDialog` с циклом `exec()`. Если пользователь нажимает «ОК» — возвращается `True` (задача добавляется), если закрывает крестиком — `False` (задача не добавляется).
